# Nexo — Tecnologia e experiências digitais

Landing page responsiva da Nexo, criada com HTML5, CSS e JavaScript. O site apresenta as soluções, projetos conceituais, processo de trabalho, diferenciais, perguntas frequentes e formulário de contato.

## Como visualizar

Abra `index.html` no navegador ou inicie um servidor local na pasta do projeto:

```bash
npx serve .
```

As páginas `topo-demo.html`, `scroll-index-demo.html` e `pointer-demo.html` demonstram os componentes interativos incluídos no projeto.

## Estrutura

- `index.html`, `styles.css` e `script.js`: landing page principal.
- `components/kokonutui/`: componentes Topo Background e Scroll Index, com versões JavaScript e React.
- `components/magicui/`: componente Pointer, com versões JavaScript e React.
- `lib/utils.ts`: utilitários compartilhados.
